# CICD Pipelines

## Task 1
This project demonstrates a CI pipeline for a simple python application, it automatically:
- Runs checkout code action to copy the repo into the pipelines VM.
- Installs independencies
- Runs linting and unit testing
- Builds a docker image & pushes it to docker hub.

## Task 2
This projects demonstrates a CICD pipeline for the deployment of a simple application.
- Configure cloud infrastructure with IaC via Terraform.
- Runs checkout code action to copy the repo into the pipelines VM.
- Installs independencies
- Runs linting and unit testing
- Builds a docker image & pushes it to docker hub.
- Automate deployment to the EC2 instance via github actions.
- Runs docker compose to run both the app container and redis container on one network.
